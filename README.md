# OpenQore

> A community-driven firmware layer to unlock advanced features on Soundcore wireless headphones.

## ✨ Features
* **Custom EQ**: Expanded parametric equalizer bands.
* **Smart ANC**: Automated mode switching based on noise levels.
* **Low Latency**: Optimized Bluetooth codec handshakes.

## 🚀 Getting Started

### Installation
```bash
git clone https://github.com
cd openqore
pip install -r requirements.txt
```

### Usage
Run the diagnostics tool with your device connected via Bluetooth:
```bash
python main.py --device "Life Q35"
```
